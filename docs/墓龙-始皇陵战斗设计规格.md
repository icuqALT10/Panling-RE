# 墓龙 · 始皇陵副本 Boss 实现规格（v1）

> 用途：交付给 **GPT6-Astra** 制作动画与战斗逻辑。
> 本文所有长度单位为**格**（Blocks），时间单位为**秒**或 **tick**（1 秒 = 20 tick）。
> 墓龙游戏内体量：**长约 40 格、高约 26 格、身体宽约 3 格**。所有攻击判定必须按这个体量设计，
> 不要按"一条小蛇"的直觉做。

---

## 0. 总览

| 项 | 内容 |
|---|---|
| 副本 | 始皇陵（倒数第二关） |
| Boss | 墓龙（GraveDragon），两种形态：`GROUND` / `AIR` |
| 战斗场地 | 主殿：开阔、有天井、可破坏石柱、中央结界法阵、尽头棺椁通道 |
| 设计基调 | 怪物猎人式：**读招 → 走位 → 惩罚窗口**；每一招都必须有明确解法 |
| 战斗时长目标 | 8~12 分钟 |
| 结局分支 | 击杀 / 用结界困住后击杀 / 让它逃入棺椁（强化始皇） |

### 0.1 三条铁律

1. **三段式**：每一招 = 预警（tell）→ 判定（active）→ 硬直（recovery）。缺一不可。
2. **有解法**：没有明确解法的招不要做。
3. **硬直是玩家的**：大招后必须给 1.5~4 秒输出窗口。无缝连招 = 耍赖。

### 0.2 形态与高度

| 形态 | 锚点高度 | 说明 |
|---|---|---|
| `GROUND` | 站地面，脚底贴地 | 身体横长条，头部是弱点 |
| `AIR` | 离地 **≥ 12 格** | 身体向锚点下方伸出约 11.5 格，所以离地低于 12 格时飞行姿态会插进地面 |

> 巡航高度常量已存在于代码：`FLIGHT_CLEARANCE = 12.0`，`FLIGHT_BODY_DEPTH = 11.5`。
> 起飞净空判定已实现为"把 fly / idle_air 姿态逐碰撞箱摆到巡航高度、任一箱插入方块则不许起飞"。

## 1. 攻击表结构（给 Astra 的数据契约）

每一条攻击用一个结构描述，建议实现成一张表：

```
Attack {
  id            : 字符串，唯一标识（见下表）
  form          : GROUND | AIR | ANY        // 只能在该形态出招
  animWindup    : 动画名（预警段）
  animActive    : 动画名（判定段）
  animRecover   : 动画名（硬直段）
  totalTicks    : 整招总时长（tick）
  tellTicks     : 预警时长（玩家可反应的时间）
  activeTicks   : 判定时长
  recoverTicks  : 硬直时长（玩家输出窗口）
  triggers      : [ { tick: N, action: 动作 } ]   // 判定/特效触发点
  hits          : [ { tick: N, shape: 形状, damage: 伤害, knockback: 击退, part: 用哪个部位判定 } ]
  weight        : 基础权重
  rangeMin/Max  : 适用的玩家距离区间（格）
  cooldownTicks : 冷却
  interruptible : 能否被破头/伤害打断
  chain         : 可选，连携到哪一招
  solution      : 文字，这一招玩家该怎么躲（用于设计校验，不参与运行）
}
```

**判定触发一律用动画时间轴上的 tick，不要写死在 tick 计数里**——否则改动画就要改代码。

## 2. 攻击详解

### A1 · 画龙点睛（空中→地面）★核心招式

| 项 | 值 |
|---|---|
| id | `air_dive_slam` |
| 形态 | AIR |
| 总时长 | 240 tick（12 s） |
| 分配 | 升空 90 / 锁定 30 / 下砸 20 / 落地硬直 100 |

**表现分解**
1. **螺旋升空（0~90 tick）**：边盘旋边垂直上升 25~35 格，同时水平朝玩家位置靠拢。
   盘旋圈直径 12~16 格，转速约 12 秒/圈。此时**不造成伤害**。
2. **锁定（90~120 tick）**：升到最高点悬停，头部朝下对准玩家当前位置。
   地面出现一个**逐渐收紧的红圈**（半径 12 → 8 格），并在 100 tick 时定死落点。
   - 红圈必须在 100 tick 前保持可见，玩家有 1 秒反应时间。
3. **下砸（120~140 tick）**：垂直下砸，速度 4 格/tick，20 tick 内落到底。
4. **落地硬直（140~240 tick）**：砸地激起冲击波，龙首/前爪贴地，尾部翘起。

**判定**
| tick | 形状 | 伤害 | 击退 | 判定部位 |
|---|---|---|---|---|
| 138 | 圆柱（半径 8，高 6） | 玩家最大生命 **35%** | 2.5 格/上抛 | 头（`head`）+ 前爪 |
| 140 | 全场冲击波（半径 20，环形，高 2） | 最大生命 **10%** | 1.5 格 | 无部位（纯环境） |

**解法**：红圈锁定后在 1 秒内跑出 8 格半径；冲击波用**跳跃**躲（冲击波高度只有 2 格）。
**惩罚窗口**：140~240 tick 头部贴地，是**破头最佳时机**（打头 2.0× 倍率）。

**Astra 需要产出**：`air_dive_windup`（盘旋上升，90 tick）、`air_dive_hold`（悬停锁定，30 tick）、
`air_dive_slam`（下砸，20 tick）、`air_dive_recover`（贴地硬直，100 tick）。

### A2 · 盘身落雷（空中）★核心招式

| 项 | 值 |
|---|---|
| id | `air_coil_lightning` |
| 形态 | AIR |
| 总时长 | 300 tick（15 s） |
| 分配 | 盘圈 80 / 穿圈 40 / 落雷 60 / 回位 60 / 收尾 60 |

**表现分解**
1. **盘圈（0~80 tick）**：身体在空中盘成一个**直径 20~24 格的水平圆环**，头部在外侧。
   这是这条龙独有的形态，务必让身体真正闭合成环（可用动画 + 参数化轨道）。
2. **头穿圈而下（80~120 tick）**：头部从圆环中心**向下穿出**，同时身体保持盘着。
   场地出现 **6~10 个红圈**，从半径 1 格逐渐放大到 5~7 格。
3. **抬头钻回（120~180 tick）**：头部抬起钻回圈中，红圈在此时达到最大并**锁定**。
4. **落雷（180~240 tick）**：**每个红圈中心劈下一道闪电**，伤害结算。
5. **回位（240~300 tick）**：身体解开盘绕，回到 `idle_air`。

**判定**
| tick | 形状 | 伤害 | 备注 |
|---|---|---|---|
| 180 / 195 / 210 / 225 / 240 | 每道雷：圆柱（半径 2.5，高 40） | 每道最大生命 **18%** | 5 波，红圈处各一道；**同一次落雷不重叠伤害** |
| 整段 0~300 | 盘绕的身体（逐碰撞箱） | 每秒最大生命 **4%** | 身体是危险区，别贴着盘圈站 |

**解法**：红圈边缘走位（圈内有雷、圈外安全）；不要站在两个红圈之间——落雷有 5 波，会补刀。
被身体扫到只是低伤，但会被推离安全位。
**惩罚窗口**：180~240 期间身体基本静止，可安全输出颈部（1.0×）。

**Astra 需要产出**：`air_ring_coil`（盘圈，80 tick）、`air_ring_dive`（头穿圈而下，40 tick）、
`air_ring_rise`（抬头钻回，60 tick）、`air_ring_hold`（盘着静止待雷，60 tick）、
`air_ring_release`（解盘回 idle_air，60 tick）。
**注意**：这个动画需要**参数化**——红圈位置要由出招时随机 6~10 个点决定，动画本身只负责"盘着 + 头穿圈"，
不要在每个红圈位置各做一套动画。

### A3 · 50% 全场吐火（强制转阶段）

| 项 | 值 |
|---|---|
| id | `phase50_firefield` |
| 形态 | 强制切 AIR（无论当前形态） |
| 触发 | **血量首次 ≤ 50%**，不参与随机，立即打断当前动作 |
| 总时长 | 400 tick（20 s） |
| 分配 | 起身/转场 60 / 蓄力 60 / 吐火 200 / 收尾 80 |

**表现分解**
1. **转场（0~60 tick）**：无视重力垂直升起 20 格（不是起飞动画，是**强制抬升**），
   全场镜头轻微震动，地面机关纹路亮起（场景联动）。
2. **蓄力（60~120 tick）**：头部后仰，口中聚集光球。
   - **火色判定（破头机制）**：在 **120 tick 这一刻**结算。
     - 若此前**头部累计伤害 ≥ 阈值**（建议为墓龙最大生命的 12%）→ **红火（低伤）**
     - 否则 → **蓝火（高伤）**
   - 光球颜色必须让玩家一眼看出（红/蓝），并在 HUD 或粒子颜色上体现。
3. **吐火（120~320 tick）**：朝场地**水平铺满**的火焰，覆盖全场 96×96 区域，
   高度 0~3 格（贴身者会被烧到，**跳起或站在高台上可躲**）。
4. **收尾（320~400 tick）**：火焰渐退，回到 `idle_air`。

**判定**
| tick | 形状 | 红火伤害 | 蓝火伤害 |
|---|---|---|---|
| 120~320 | 全场（96×96×3） | 每秒最大生命 **8%** | 每秒最大生命 **18%** |

**解法**：
- 进**石柱掩体后方**（掩体形成安全区），或
- 跳上**高台**（火焰只有 3 格高），或
- **开场就破头**，把蓝火降级成红火。

**Astra 需要产出**：`phase50_rise`（强制抬升，60 tick）、`phase50_charge`（蓄力，60 tick）、
`phase50_fire_loop`（吐火循环，200 tick，需可循环）、`phase50_fire_end`（收尾，80 tick）。
**特效**：火焰粒子用大面积粒子发射器，红/蓝两套材质。

### A4 · 龙车（地面）★核心招式

| 项 | 值 |
|---|---|
| id | `ground_charge` |
| 形态 | GROUND |
| 总时长 | 180 tick（9 s） |
| 分配 | 预警 40 / 冲刺 60 / 撞墙或收势 20 / 硬直 60 |

**表现分解**
1. **预警（0~40 tick）**：头压低至地面高度、前爪刨地、身体后缩，发出低吼。
   地面沿冲刺方向出现**直线方向指示**（可选，用于新手引导）。
2. **冲刺（40~100 tick）**：以 2.2 格/tick 直线前冲，最长冲 60 tick（≈130 格，足以穿全场）。
3. **撞墙（100~120 tick）**：若撞到场地边界或石柱 → 进入 **额外 60 tick 硬直**，头部眩晕。
4. **收势**：若没撞墙则在 100 tick 减速停下，进入 60 tick 硬直。

**判定**
| tick | 形状 | 伤害 | 击退 |
|---|---|---|---|
| 40~100 | 头部前方盒（8 宽 × 6 高 × 6 长） | 最大生命 **22%** | 3 格 + 上抛 |
| 40~100 | 整条身体（逐碰撞箱，宽 3） | 最大生命 **12%** | 2 格 |

**解法**：**侧向闪避**（不要在直线上后退，它比你快）；或**绕到侧后**——冲刺时转向很慢。
**惩罚窗口**：撞墙后 60 tick 头部眩晕，是**最佳输出时机**。

**Astra 需要产出**：`ground_charge_windup`（低头刨地，40 tick）、`ground_charge_loop`（冲刺循环，60 tick）、
`ground_charge_impact`（撞墙，20 tick）、`ground_charge_stagger`（硬直/眩晕，60 tick）。

### A5 · 八向爪击 / 甩尾（地面）★核心招式

| 项 | 值 |
|---|---|
| id | `ground_claw`（爪击） / `ground_tailsweep`（甩尾） |
| 形态 | GROUND |
| 总时长 | 爪击 140 tick / 甩尾 160 tick |
| 分配 | 预警 45 / 判定 15 / 硬直 80 |

**方向决策（八向）**
把场地分成 8 个 45° 扇区，统计**每个扇区内玩家**，按优先级选一个方向：

```
优先级 1：扇区内玩家数量最多
优先级 2（数量相同）：扇区内玩家总血量最低
优先级 3（仍相同）：扇区内离墓龙最近
```

**分支**
- 选中的扇区在**正前方 3 个扇区**（-45° ~ +45°）内 → **爪击**：抬起离玩家最近的那只前爪挥下。
- 选中的扇区在**后方 3 个扇区**（135° ~ 225°）内 → **甩尾**：尾巴横扫该方向。
- 两侧扇区（±45°~135°）→ 抬起对应侧前爪，或转身后爪击（Astra 可只用"抬同侧爪"简化）。

**判定**
| 招式 | tick | 形状 | 伤害 | 击退 |
|---|---|---|---|---|
| 爪击 | 45~60 | 爪部盒（6×6×6，随爪移动） | 最大生命 **18%** | 2 格 |
| 甩尾 | 45~60 | 尾部 180° 扇形（半径 20，高 4） | 最大生命 **15%** | 2.5 格 + 击飞 |

**解法**：
- 爪击：看它抬哪只爪 → 往**另一侧**走。抬爪动作必须清晰可读（爪子高过头顶）。
- 甩尾：**跳起**（尾扫高度只有 4 格），或贴身到颈部（尾巴够不到）。
**惩罚窗口**：硬直 80 tick，头部前伸，可打头。

**Astra 需要产出**：`ground_claw_windup_l` / `ground_claw_windup_r`（抬左/右爪，45 tick）、
`ground_claw_hit_l` / `_r`（挥下，15 tick）、`ground_claw_recover`（收爪，80 tick）、
`ground_tailsweep_windup`（身体蓄力侧倾，45 tick）、`ground_tailsweep`（尾扫，15 tick）、
`ground_tailsweep_recover`（80 tick）。

### A6 · 猛转身一字火（地面）★核心招式

| 项 | 值 |
|---|---|
| id | `ground_turn_breath` |
| 形态 | GROUND |
| 总时长 | 200 tick（10 s） |
| 分配 | 转身 50 / 蓄力 30 / 吐息 80 / 硬直 40 |

**表现分解**
1. **转身（0~50 tick）**：按 A5 的同款"数量 > 血量 > 距离"优先级选定方向，
   然后**猛地转身**面向该方向（转身速度约 8°/tick，有惯性感）。
2. **蓄力（50~80 tick）**：头后仰、口中聚火，地面沿朝向出现**扇形预警**（±15°，长 30 格）。
3. **吐息（80~160 tick）**：沿朝向吐出"一字火"——**细长直线火柱**，宽 6 格、长 30 格、持续 80 tick。
   吐息期间头部**缓慢左右扫**（±10°），逼玩家继续移动。
4. **硬直（160~200 tick）**：低头喘息。

**判定**
| tick | 形状 | 伤害 |
|---|---|---|
| 80~160 | 直线火柱（宽 6，长 30，高 4） | 每秒最大生命 **20%** |

**解法**：**跑到它身后**（转身慢，是明确的绕背窗口）；或横向跑出 30 格。
**惩罚窗口**：160~200 tick 低头，头部弱点暴露。

**Astra 需要产出**：`ground_turn`（猛转身，50 tick）、`ground_breath_windup`（蓄力，30 tick）、
`ground_breath_loop`（吐息循环，80 tick）、`ground_breath_end`（硬直，40 tick）。

### A7 · 前爪下砸（地面）★核心招式

| 项 | 值 |
|---|---|
| id | `ground_slam` |
| 形态 | GROUND |
| 触发条件 | 有玩家在**正前方 12 格内** |
| 总时长 | 160 tick（8 s） |
| 分配 | 预警 50 / 砸下 10 / 硬直 100 |

**表现分解**
1. **预警（0~50 tick）**：**后腿站立、前爪高高抬起**（身体呈 45° 上仰），
   两个前爪落点出现红圈（半径 5 格）。
2. **砸下（50~60 tick）**：双爪猛砸地面，地面出现放射状裂纹，扬尘。
3. **硬直（60~160 tick）**：前身伏地，前爪插在地里（拔不出来），尾部微微摆动。

**判定**
| tick | 形状 | 伤害 | 击退 |
|---|---|---|---|
| 50~60 | 双爪盒（10 宽 × 8 高 × 8 长，两个） | 最大生命 **25%** | 3 格 + 震慑 |
| 50~62 | 冲击波（半径 10 环形，高 2） | 最大生命 **8%** | 1 格 |

**解法**：跑出双爪红圈（红圈提示明确）；冲击波跳跃躲。
**惩罚窗口**：60~160 tick 是最长的硬直，**100 tick 免费输出**，且头部低垂。

**Astra 需要产出**：`ground_slam_windup`（后腿站立抬爪，50 tick）、`ground_slam_hit`（砸下，10 tick）、
`ground_slam_stuck`（伏地拔爪，100 tick）。

## 3. 建议补充的招式（让手感更"怪猎"）

按**建议实现优先级**排序。前 6 个强烈建议做。

### B1 · 盘身绞杀（地面）★长条身体独有

- id `ground_coil`｜总时长 220 tick｜预警 60 / 收缩 80 / 松开 80
- **表现**：身体绕着玩家所在位置盘 1.5 圈，然后**收缩收紧**。
- **判定**：收缩期间身体逐碰撞箱造成每秒 5% 最大生命 + **移动速度 -60% 的"受困"效果 2 秒**（被完全圈住时）。
- **预警**：身体开始向内弧线移动（玩家能从龙头轨迹读出"要盘我"）。
- **解法**：**从圈还没合拢的缺口冲出去**（这是全游戏最独特的解法，务必让缺口明显）。
- **为什么做**：只有长条身体能"盘人"，是这条龙的招牌。

### B2 · 尾扫 + 原地翻滚（地面）★

- id `ground_tailroll`｜总时长 180 tick｜预警 50 / 扫尾 15 / 翻滚 40 / 硬直 75
- **表现**：后半个身体抬起，尾扫 270°，随后身体翻滚换边（换到场地另一侧）。
- **判定**：尾巴 0.75 秒（15 tick），最大生命 20%，击退 3 格。
- **解法**：跳起，或提前贴身到颈部安全位。
- **作用**：位移 + 攻击二合一，打破"它总是原地出招"的呆板感。

### B3 · 龙吼（地面/空中通用）★破节奏

- id `roar`｜总时长 120 tick｜预警 36 / 判定 24 / 硬直 60
- **表现**：抬头张嘴长啸，屏幕震动 + 风压粒子，全场可听见。
- **判定**：全场最大生命 6% + **眩晕 1.5 秒**（可被"耳塞"类装备/药水免疫 → 给你地图的装备一个价值点）。
- **预警**：36 tick（1.8 秒）头部明显后仰，足够可读。
- **连携**：`roar → ground_charge`（经典"吼完就撞"），但连携后必须给 2 秒以上窗口。

### B4 · 火焰地带（地面）★场地控制

- id `ground_firezone`｜总时长 200 tick｜预警 40 / 吐火 40 / 场地燃烧 120
- **表现**：朝地面吐 3~5 团火，落地形成**持续 8 秒的火区**（半径 6 格）。
- **判定**：火区内每秒最大生命 6%。
- **作用**：压缩走位空间，让后续 A4/A7 更难躲。**这是黑龙设计的精髓**——不是为了伤害，是为了限制站位。

### B5 · 尾部针刺雨（空中）★

- id `air_spikerain`｜总时长 200 tick｜预警 40 / 投刺 100 / 硬直 60
- **表现**：悬浮高空，尾尖朝下连续抖动，向全场**随机 12~20 个点**投刺。
- **判定**：每根刺落地小范围（半径 2）最大生命 10%。
- **作用**：给远程/法系玩家压力，逼他们也不能站桩。

### B6 · 贴地扫描焰（地面，血量 ≤60%）

- id `ground_sweep_breath`｜总时长 220 tick｜预警 50 / 扫描 120 / 硬直 50
- **表现**：头贴地，横向扫出一条**扇形火线**，随头转动。
- **判定**：持续每秒最大生命 16%。
- **解法**：绕到它**转头速度跟不上的那一侧**（转头角速度 < 15°/tick），给玩家明确的"绕背"答案。

### B7 · 空中火球三连（空中）

- id `air_fireball3`｜总时长 180 tick｜预警 40 / 三连发 60 / 硬直 80
- **表现**：三连吐火球，**每颗都带轻微追踪**（转向率 6°/tick）。
- **判定**：每颗命中最大生命 12%，爆炸半径 4。
- **解法**：不要直线跑，要"拉一个角度再折返"（利用追踪转向率有限）。

### B8 · 陵墓震击（地面，场景联动）

- id `ground_quake`｜总时长 240 tick｜预警 60 / 震击 20 / 地形变化 40 / 硬直 120
- **表现**：双爪砸地，**地面纹路亮起**，若干石柱升起或塌陷（改变战场）。
- **判定**：全场最大生命 12% + 站立不稳（0.5 秒）。
- **作用**：把"场景"和"战斗"绑起来；新地形可被玩家用来躲后续招。

### B9 · 俯冲尘暴（空中→地面转场）

- id `air_dustdive`｜总时长 160 tick
- **表现**：从高空俯冲落地，激起全场沙尘，**视野受限 3 秒**。
- **作用**：形态转换的过场演出，同时制造"看不见但听得见"的紧张感。

### B10 · 濒死挣扎（10% 血，逃跑前）

- id `dying_thrash`｜总时长 400 tick（20 s）
- **表现**：疯狂甩头 + 无规律尾扫 + 短促吐息，全场乱打。
- **作用**：给"收割窗口"制造压迫感——玩家要在混乱中打死它或开结界。

## 4. 部件倍率与破坏机制

现有 79 个部件碰撞箱已按骨骼分组（`HARD_CODED_PART_BOUNDS` + `PART_LABELS`）。
建议按部位分四档伤害倍率：

| 部位 | 部件标签 | 倍率 | 破坏阈值 | 破坏效果 |
|---|---|---|---|---|
| 头 / 下颚 | `head`, `jaw`, `upper_jaw`, `horn_*` | **2.0×** | 累计伤害 ≥ 最大生命 12% | **破头**：A3 的蓝火降级为红火；所有吐息射程 -20% |
| 颈节 | `neck_01`~`neck_11`, `neck_joint` | 1.0× | — | — |
| 躯干 / 爪 | `front_*`, `hind_*`, `tail_01`~`tail_02` | 0.8× | 每只前爪累计 ≥ 最大生命 8% | **破爪**：A4 龙车距离减半；A5 爪击预警 +0.4 s |
| 尾 | `tail_03`~`tail_tip` | 0.6× | 尾累计 ≥ 最大生命 10% | **断尾**：A5 甩尾半径 20 → 12；B5 尾针数量减半 |

**设计意图**：鼓励玩家打不同部位，而不是无脑砍一个点。

## 5. AI 选招逻辑

不要写复杂效用函数。用"**条件 + 权重 + 冷却 + 不重复**"：

```
每 10 tick 评估一次（正在出招时不评估）：
  1. 若正在出招 → 继续，直到硬直结束
  2. 候选 = 所有满足条件的招
     条件 = 形态匹配 AND 距离在 [rangeMin, rangeMax] AND 冷却已过 AND 非上两招
  3. 权重 = 基础权重 × 距离系数 × 阶段系数
     距离系数：近身招在 0~8 格 ×2.0，8~20 格 ×1.0，>20 格 ×0.2
     阶段系数：血量 >70% ×1.0；40~70% ×1.2；<40% ×1.5（大招更频繁）
  4. 加权随机抽一个
  5. 硬直结束后强制 16 tick（0.8 s）"观察期"，不做任何事
```

**强制规则**
- 同一招 300 tick（15 s）内不重复。
- 血量 50% 与 10% 是**强制招**，不参与随机。
- **永远保证近身与远程各至少有一招可用**（避免玩家躲死角刷伤害）。
- 阶段过渡招（A3、B10）可以打断当前动作。

## 6. 逃入棺椁（10% 血）· 关卡机制

### 阶段 1：开门（10% 血触发）
- 墓龙停止攻击，转向场地尽头的**棺椁通道**，播放 `flee_wake`（复苏蓄力，60 tick）。
- 通道门开启，发光（**视觉明确**）。
- 中央结界法阵的**3 个站位点**亮起。

### 阶段 2：倒计时（建议 600 tick = 30 s）
- 墓龙以 0.5 格/tick 缓慢向门口移动（此时**不攻击**，是纯收割窗口）。
- 玩家可以：
  - **打死它** → 最优结局
  - **开结界** → 需要 3 名玩家同时站在法阵上（或 1 名玩家持续读条 5 秒）→ 困住它
  - **什么都不做** → 它钻进去 → 始皇强化

### 阶段 3：结算
| 结果 | 后续 |
|---|---|
| 击杀 / 困住后击杀 | 始皇以**正常形态**登场 |
| 逃入棺椁 | 始皇获得额外技能（建议：开场护盾"墓龙之魂" + 龙焰吐息 + 一次召唤龙影） |

**Astra 需要产出**：`flee_wake`（转向/蓄力，60 tick）、`flee_move`（爬向门口循环）、
`flee_enter`（钻入棺椁，末尾可配合门关闭动画）。

## 7. 场景设计 · 始皇陵

### 7.1 三层空间

| 区域 | 尺寸 | 内容 | 作用 |
|---|---|---|---|
| **① 前殿（机关区）** | 64 × 48 | 立柱 8 根、高台 2 处、机关 3 组 | 破解机关 → 触发龙复苏；教玩家"柱子能卡视线" |
| **② 主殿（战斗区）** | **96 × 96**，天井高 **64** | 可破坏石柱 6 根、中央结界法阵、地面机关纹路、四周高台 | 主战场 |
| **③ 棺椁通道** | 24 × 48 | 门 + 棺椁 | 逃跑目标点；成功后门关闭并发光 |

> **尺寸依据**：龙长 40 格、A4 龙车要冲 130 格、A2 盘圈直径 24 格、A3 全场火覆盖 96×96。
> 主殿 **不能小于 96×96**，否则龙车和盘圈会撞墙。

### 7.2 主殿要素

| 要素 | 规格 | 与战斗的关系 |
|---|---|---|
| **可破坏石柱** | 6 根，直径 4、高 20，位置对称 | 打断后**倒下的柱体形成掩体**，可挡 A3 全场火与 A6 火柱；也可被 A4 龙车撞断 |
| **中央结界法阵** | 直径 24 的圆形台，3 个站位点（相距 8 格） | 10% 阶段的困龙机制 |
| **地面机关纹路** | 全场环形纹路 | 血量过 50% 亮起（预告 A3）；B8 震击时亮起 |
| **四周高台** | 4 座，高 4~6 格，宽 12 | **站在上面可躲 A3 的 3 格高火焰**；也躲避 A4 龙车（龙车撞高台会卡住） |
| **天井** | 顶部开口 32 × 32 | 空中招式（A1 升空、A2 落雷、B5 针雨）从上方进入，视觉上"从天而降" |
| **棺椁通道口** | 主殿一端，宽 12、高 16 | 10% 阶段的逃跑目标 |

### 7.3 场地演进（让战场也在"打"）

| 触发 | 变化 |
|---|---|
| 战斗开始 | 6 根石柱完好 |
| 血量 ≤ 75% | 最外侧 2 根石柱塌陷，露出火池（踏入灼烧） |
| 血量 ≤ 50% | 地面纹路亮起；中央法阵通电（视觉） |
| 血量 ≤ 25% | 天井开始掉落碎石（随机小范围伤害，逼玩家移动） |
| 血量 ≤ 10% | 棺椁通道门开启 |

### 7.4 玩家可提前交互的布局

进本前玩家能准备的东西（让"提前布局"有意义）：
- **结界符石**：放在法阵站位点上，可单人启动结界（否则需要 3 人）
- **石柱加固**：延缓石柱被龙车撞断
- **高台护栏**：防止被 A4 撞飞时摔落
