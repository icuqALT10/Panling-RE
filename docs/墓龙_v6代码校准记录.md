## 本轮修改

- 重新拟合 79 个 OBB，保留 ID 和破坏映射；不将零厚度鬃毛/胡须/爪牙装饰面扩充为碰撞实体。
- 上肢原 `_a/_b` ID 分别覆盖肩块和主干，小臂仍分两段。肩块、指节和龙角保留几何自身旋转，避免轴对齐大盒包住空处。
- 旧表部分躯干中心比最终模型高约 1.5 格，四肢中心/长度滞后。本轮按真实几何重算，而非整体放大旧表。
- 动画非等比缩放与局部旋转组合会产生剪切；对此重新建立正交轴、投影半边向量拟合包围 OBB，满足 SAT 的正交前提。正常姿态继续紧贴原几何。
- 吐息/火球改从上下颌前端之间发出。选招预测、正式发射和吐息特效共用嘴部取点，不再从脑袋中心喷出。
- 火环用起火时嘴部地面投影；侧压取躯干至后腿根部的边缘，修正后半身范围遗漏。
- 移除旧模型固定 11.5 格向下深度假设；起飞继续以实际多相位 OBB 检查方块，巡航锚点离地 12 格保留。
