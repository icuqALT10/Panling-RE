# 墓龙：20 套普攻与技能总设计

2026-10-02，设计草案。本稿暂按当前正在推进的墓龙整理；用户此次“他”的指代尚待确认。仅提出动作与玩法，不修改模型、动画、Java 或副本场景。

总量：20 套普通攻击连段、16 个常规技能、1 个保留的半血阶段技能。左右镜像不重复计数，已有单招动画也不冒充新连段已经做好。始皇五行牌、骑龙歼灭斩另见始皇设计，不塞进墓龙独立战。

## 一、普攻与技能的区别

- 普攻以爪、牙、颌、肩、躯干和尾部的可见接触为主；每套 2～5 个动作，一次完整起势和收势，中间不反复切待机。剑气、落雷、火场等远距离效果不用于扩大普通攻击。
- 技能拥有更明显的蓄势、独立效果和覆盖区域，承担远程压制、逼走位或阶段变化。龙车、俯冲等大位移动作也保留为技能。
- 龙头先观察，肩髋承重，颈尾逐节跟随。沉重的大型龙依靠支撑和连续弯曲发力，不高速原地自转，不让身体每一段同时转向。
- 地面常态仍是技能间待机；接近、侧移、升降只能是当前招式明确需要的动作，不能借新连段恢复随机游走。

## 二、20 套普通攻击连段

下列都是拟制作的完整连段。借用旧招的动作意图时，需要重做承重、收势和过渡，不能将现有独立剪辑首尾硬接。

| 编号 | 名称 | 连贯动作 | 用途与玩家应对 |
| --- | --- | --- | --- |
| A01 | 探爪折颈 | 单前爪向内横划 → 同侧肩落地承重 → 龙头沿另一条弧线短咬 | 基础前侧两连；躲过爪后向龙头外侧走，不能立刻钻回嘴前 |
| A02 | 双门裂爪 | 左前爪斜下划 → 右前爪横切 → 右掌翻腕下压 | 正面三连、快快重；前两击用走位避开，第三击落地后反击 |
| A03 | 探咬回撕 | 短促前咬 → 收颈避开近身 → 横向回咬 | 对付贴脸绕圈；第二击沿横向而非继续直冲，需退到颈弧外 |
| A04 | 颔挑镇首 | 低头收颌 → 下颌向上挑击 → 前额向前下方顶压 | 近身高低变化；第一击后向侧外方离开，不靠连续后跳硬躲 |
| A05 | 叩地扫堂 | 单掌垂直叩下 → 手肘外开 → 同掌贴地向外扫 | 对付固定站在前脚侧面；看到抬掌先离落点，再越过已经扫空的一侧 |
| A06 | 踏步连逼 | 左右前掌交替向前踏击 → 后腿蹬地 → 双掌短推 | 有限步进压迫；不永久追人，横移可退出前进通道 |
| A07 | 折返猎咬 | 斜前探身咬击 → 前爪换撑调整肩向 → 向另一侧短咬 | 对付横向奔跑；转向在第二次咬之前完成，出咬后不继续追踪 |
| A08 | 双噬追猎 | 长颈收缩蓄力 → 第一次前扑咬 → 重新找最近目标 → 第二次前扑咬 | 沿用既有双咬，各推进 10 格；读第二次抬颈而非盲目按第一条线路躲 |
| A09 | 侧肩崩 | 肩向一侧沉下 → 短距侧肩撞 → 龙头绕肩补一记侧咬 | 驱赶肩旁贴身玩家；本套只判实体接触，不附侧压技能的 8 格喷流 |
| A10 | 回爪封肋 | 前掌向腹侧回捞 → 重心移到另一侧 → 同侧后爪向外划击 | 覆盖前后腿之间的侧腹；沿龙身向头或尾离开，不能停在腹侧 |
| A11 | 振胯后踢 | 抬起一侧后爪向后蹬 → 落脚承重 → 另一后爪补踏 | 后方短连；抬胯是前兆，避开抬起的后爪投影后再近身 |
| A12 | 卷尾回锋 | 尾部低位横扫 → 中段继续蓄扭 → 尾尖沿反向弧线回鞭 | 横扫后追加反向击；第二击有持续卷尾前兆，不在第一扫后立即追尾 |
| A13 | 回身截尾 | 颈部偏向目标并扭胯 → 尾尖从另一侧斜切 → 尾末端顺势甩出 | 头部关注方向与尾击来向不同；以尾部卷向判断落区，不只盯龙头 |
| A14 | 摆尾叩地 | 尾部横扫 → 抬起末端略蓄 → 尾尖垂直下砸 | 横向接纵向；只判尾部实体接触，大范围地震另属技能 |
| A15 | 钩尾挑身 | 尾段由外向内收拢扫击 → 尾尖向斜上方抽挑 → 后掌补压近处 | 防止一直贴着尾根绕行；尾弧收拢前退出其开口，不默认抓取或锁住玩家 |
| A16 | 俯身剪击 | 两前爪从两侧向中间合划 → 双掌分开支撑 → 低头直咬 | 两爪同时合击算一段，不叠两份伤害；后退离开夹击区后绕侧 |
| A17 | 沉躯覆压 | 前身抬起、后腿承重 → 双掌与胸前压落 → 低颈向前顶出 | 压制正下方；有明显抬胸预备，可从前腿外侧退出，身体不是全程接触伤害 |
| A18 | 低空掠爪 | 从空中低掠 → 左右前爪先后斜划 → 抬肩上扬收爪 | 空中近战两连；地面有掠行方向提示，向航线侧方移动；需要足够净空才入选 |
| A19 | 踏落追爪 | 低空伸前爪向前踏落 → 后爪落地接重 → 肩向前推接短咬 | 空地衔接；落地只有爪接触伤害，没有俯冲技能的大范围爆震；落地后仍有短咬 |
| A20 | 龙威五势 | 单爪斜划 → 短咬 → 侧肩推撞 → 转髋带尾扫 → 回正重掌 | 低血时的完整长连；攻击依次换方向，末击后留最长收势，不能无限续段 |

差异验收：A03 是收颈后的横向回咬，A07 是支撑脚换向的短追咬，A08 是两段明确的大步前扑；A12 是反向回鞭，A13 是由扭胯驱动的斜向尾截，A14 是横扫接垂直砸。这些区别必须反映在轨迹和玩家应对中，不能仅改名字或速度。

## 三、16 个常规技能

S01～S12 归纳已有招式机制；名称是本稿便于讨论的设计名，不表示动画或代码标识已改名。S13～S16 为本次新增提案。所有普通技能保留可应对路线，不能套用始皇歼灭斩的必中特例。

| 编号 | 名称 | 动作与效果 | 前兆、应对和收势 |
| --- | --- | --- | --- |
| S01 | 扇炎扫庭 | 沉头张口喷出 30 格、60° 扇形火焰；无落地扩散 | 咽喉先亮、颈部压低；离开扇形两侧，结束后抬头收息 |
| S02 | 回首焚线 | 先侧头收颈，再转颈扫出长条吐息；保留已有转身/横扫分型及各自地面扩散 | 头颈转向展示扫掠方向；从尚未扫到的一侧脱离，不在脚边无限转圈锁定 |
| S03 | 裂地三锋 | 双前爪压地，爪前生成三颗呈扇形展开的滚石 | 先显示三条地裂方向；从射线夹角走，石头按既定速度滚动至墙或 80 格 |
| S04 | 崩山侧震 | 身体向一侧压低，沿该侧躯干喷出向外 8 格的气浪 | 左右为同一技能的变体；读压低的一侧，离開该侧带状区域 |
| S05 | 踏天火轮 | 空中俯首，火焰落地点向外扩成火环 | 中心半径 2 格安全、波前扩至 24 格；保留现有带宽和缓速，不改为整圆持续伤害 |
| S06 | 三曜流火 | 空中依次向三扇区发射火球；地面五发扇射为同一家族的既有分型 | 龙头逐次转向展示发射区，避开弹道及爆炸区；每发仍使用嘴部真实位置 |
| S07 | 镇陵雷诏 | 龙角蓄电，三轮分别重新锁定有效玩家位置并落雷 | 每轮分别给地面提示；上一轮结束不代表全技能结束，保持变向移动 |
| S08 | 盘龙雷域 | 在空中盘起躯干、龙角持续蓄电，按原盘雷技能在多个点落雷 | 保留原落点算法；先辨认地面电纹的间隙，释放后舒展身体 |
| S09 | 俯冲撼岳 | 飞高收爪，锁定区域后俯冲，以双前爪带动重砸和冲击 | 清楚显示落区；离开落点而非追着飞行龙头跑，落地后有承重收势 |
| S10 | 龙车破阵 | 压低头颈沿锁定通道前冲；撞墙与未撞墙分别收势 | 按既定冲锋范围/击退保留；启动后不能瞬间拐弯跟踪，玩家侧移避让 |
| S11 | 盘身绞阵 | 身体展开后连续盘转，以既定盘身区域产生挤压与击退 | 尾、躯干的盘入方向明确；不把所有模型外接矩形当成持续命中区 |
| S12 | 镇魄龙吟 | 蓄胸昂颈后咆哮，沿用原吼叫控制效果与范围 | 给出独立抬颈/吸气前兆；地面与空中只算形态变体，保留原控制规则 |
| S13 | 双角雷链（新增） | 双角分别向地面落下电端点，随后两条贴地雷线由外向内横移，合拢前断开收束 | 两条线先淡后亮，分区扫过而非全场无缝封锁；从线端或预留断口绕开，触线短促伤害、不永久禁锢 |
| S14 | 潜火伏爆（新增） | 向三处地面吐出低矮火种，咽喉脉动后按放置顺序爆发 | 每处火种有清楚亮度倒计时；不沿玩家脚下无限追生，不改地形；爆完回到干净地面 |
| S15 | 玄风回廊（新增） | 龙头先压出一道笔直风廊，紧接身尾沿同方向掠过，形成“先风压、后肉身”的双层攻击 | 风廊仅轻推、不中断移动；离开宽带即可同时避开后续龙身，飞掠后必须缓冲转弯 |
| S16 | 龙脉交震（新增） | 一只前爪压地发出纵向裂震，另一只爪稍后叩下横向裂震，两道在旧目标点交叉 | 十字两笔分先后、每笔独立预告；锁点后不跟玩家移动，四个斜角均可撤离，不真实破坏地板 |

新技能初始调试建议（待模型/战场尺度验收）：S13 单条雷线有效段约 12 格、横移约 8 格；S14 三处各半径约 4 格，爆发间隔约 0.5 秒；S15 风廊宽约 6 格、长约 24 格；S16 两道裂震各长约 24 格、宽约 3 格，第二道晚约 0.6 秒。它们不是用户已定数值，也不反向覆盖现有技能范围。所有路径须按实际可达空间选取。

## 四、半血阶段技能单独保留

**P01 业火封陵**：保留当前 `phase50_firefield` 的半血触发、长时间大喷火和落地扩散规则，不用“简化技能”删除扩散。它不进入普通随机技能池，也不挤占上述 16 个常规技能。

5% 锁血与逃跑属于副本剧情，不计入普攻或技能数量，本轮不改控制器。始皇骑龙的帝皇歼灭斩亦不属于墓龙独立战的半血技能。

## 五、组合与选招建议

- 20 套是完整动作库，不要求同一时刻等概率投放。新系统接入时先按地面/空中、玩家位于头前/侧腹/后方以及路径可用性筛选，再按近期使用记录抽选。
- 正前常用 A01～A08/A16；侧腹常用 A09/A10；后方常用 A11～A15；贴身压制 A17；空中 A18/A19；A20 放在后半段战斗低权重使用。
- 建议一阶段先启用 10～12 套普攻，后半血补充长连和更多变向；四个新增技能可在半血之后逐渐加入。具体血线和权重后续确认，不在本轮改旧代码。
- 一套普攻打完明确收势，再决定下一套或技能，不随机把 20 套无限串成一段。连段内目标偏离范围时，按已显示的动作收空，不能瞬移追上。
- 新普攻起势暂以 0.55～0.90 秒为调试起点，连击接续约 0.20～0.45 秒，末段重击前略长；整套后通常留 0.6～1.0 秒，A20 留约 1.2 秒。既有双咬等已定动作仍以原时间为基准，不批量缩时。
- 不给所有命中添加长硬直或强击飞。新增连段的伤害要按“整套风险”重新预算，不能照搬旧高伤单招数值逐段叠满；旧代码伤害本轮不变。正常无敌帧继续保留。
- 破坏部位后排除依赖该部位的新连段/技能；多个 OBB 同一击碰到同一玩家只结算一次。原有破头伤害变化等规则延续。

## 六、制作与验收顺序

1. 先验证 A01、A02、A08、A09、A12、A14 六套，涵盖爪、咬、肩、尾、追击和上下变化。
2. 再做其余地面连段和 A18/A19 空地衔接，最后制作 A20；每套独立检查完整动作，不以旧剪辑存在宣称新连段完成。
3. 四个新增技能分别先做蓄势—释放—收势动画，再接效果与判定。当前已有 50 个动作、16 类技能归纳不等于这份新增设计已经实现。
4. 爪咬尾使用实时骨骼 OBB 扫掠；风雷火等单独按可见效果范围判定，预告、实际命中和结束事件同步。确认攻击器官在玩家高度触达、站立脚不漂、尾身不穿插、释放后有收势。
