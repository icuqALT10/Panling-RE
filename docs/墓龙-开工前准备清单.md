## 3. 场景：需要你确认产出方式与场地参数

### 3.1 产出方式（关键，我不知道你的工作流）

请选一种：

- **(a) 我生成 `.nbt` 结构文件**（沿用仓库里 `data/panlingre/structure/instance/*.nbt` 的做法），你在游戏里 `/place` 或填进世界模板；
- **(b) 我写 Java 代码**（调试用命令 / 世界生成）自动摆放；
- **(c) 我只出图纸与用料表**，你自己搭。

### 3.2 场地参数

设计规格里的下限是按龙的体量算的：**主殿 ≥ 96×96、天井高 ≥ 64**（龙长 40 格、龙车冲 130 格、盘圈直径 24 格、全场火覆盖 96×96）。

- 若你**已有房间**：请给坐标范围与净空高度，我按它调整招式参数（盘圈直径、龙车距离、火区半径）。
- 若你**还没有**：我按 96×96×64 设计，你用 (a) 或 (b) 投放。

### 3.3 表现层实现方式

红圈预警、扇形预警、直线预警、火柱、闪电、全场火焰：

- 倾向：**mod 侧粒子 + 自绘圈**（可控、可精确对应判定）；
- 替代：资源包贴图 + 命令方块；
- 请确认走哪条。
