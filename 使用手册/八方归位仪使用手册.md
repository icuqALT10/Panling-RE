# 八方归位仪 使用手册

## 概述

八方归位仪是一个传送系统。玩家手持八方归位仪右键打开界面，选择已解锁的传送点，消耗经验值后瞬间传送到目标位置。

传送点数据由 `data/panlingre/ba_fang_yi/` 下的 JSON 配置文件定义，玩家解锁进度通过指令管理，冷却时间受玩家"冷却缩减"属性影响。

---

## 物品

| 属性 | 值 |
|------|-----|
| ID | `panlingre:ba_fang_yi` |
| 中文名 | 八方归位仪 |
| 堆叠 | 1 |
| 稀有度 | ★★★ |
| 属性 | 冷却缩减 +1.0（手持时生效） |

手持右键打开传送界面。

## 配置文件

### 位置

`data/panlingre/ba_fang_yi/` 目录下，文件名任意，扩展名为 `.json`。服务端启动时自动加载。

### 基本格式

```json
{
    "title": "传送大项名称",
    "id": "unique_id",
    "texture": "panlingre:textures/gui/teleport/custom_icon.png",
    "poses": [
        {
            "title": "传送子项名称",
            "id": "sub_unique_id",
            "texture": "panlingre:textures/gui/teleport/custom_icon.png",
            "pos": { "x": 0, "y": 64, "z": 0 }
        }
    ]
}
```

### 字段说明

#### title（必填）

传送大项/子项的显示名称。支持 Minecraft 文本组件格式。

**简单文本**：
```json
"title": "下界堡垒"
```

**带颜色和格式**：
```json
"title": {
    "text": "下界堡垒",
    "color": "gold",
    "bold": true
}
```

**使用翻译键**：
```json
"title": {
    "translate": "my.custom.translation.key"
}
```

#### id（必填）

唯一标识符，用于指令解锁/查询。建议使用小写字母和下划线。

- 大项 id 和子项 id 均需唯一
- 不同大项下的子项 id 可以重复

#### texture（可选）

按钮左侧显示的图标，指向资源包中的纹理路径。

- 路径格式：`命名空间:textures/...`
- 图标建议尺寸：16×16 像素
- 不填或路径无效时使用默认图标 `panlingre:textures/gui/teleport/default_icon.png`

#### pos（子项必填）

传送目标坐标。三个轴都必须指定。

```json
"pos": { "x": 100, "y": 64, "z": -200 }
```

## 界面说明

### 一级界面（大项列表）

- 右键八方归位仪打开
- 标题：`plre.gui.ba_fang_yi.title` 翻译键的值
- 列表显示所有已解锁的大项，最多同时显示 5 个，滚轮翻页
- 每个按钮左侧显示该大项的图标
- 点击大项进入二级界面
- 未解锁的大项不显示
- 按 ESC 关闭界面

### 二级界面（子项列表）

- 标题替换为所点击大项的名称
- 每行显示 2 个传送点子项
- 每次最多显示 3 行（共 6 个按钮），滚轮翻页
- 每个按钮左侧显示该子项的图标
- 点击子项发起传送请求
- 未解锁的子项不显示
- 按 ESC 返回一级界面（大项列表）

## 指令

所有指令需要权限等级 ≥ 2，格式为 `/plre bafangyi <操作> <大项id> [子项id]`。

### 添加解锁

```
/plre bafangyi add <大项id>
/plre bafangyi add <大项id> <子项id>
```

- 解锁指定大项，使其在一级界面中可见
- 若同时指定子项，则一并解锁该子项

**示例**：
```
/plre bafangyi add overworld
/plre bafangyi add overworld village
```

### 移除解锁

```
/plre bafangyi remove <大项id>
/plre bafangyi remove <大项id> <子项id>
```

- 锁定指定大项，大项及其所有子项在一级界面中隐藏
- 若同时指定子项，则仅锁定该子项

**示例**：
```
/plre bafangyi remove overworld
/plre bafangyi remove overworld village
```

### 查询解锁状态

```
/plre bafangyi query <大项id>
/plre bafangyi query <大项id> <子项id>
```

- 查询指定大项/子项是否已解锁

**示例**：
```
/plre bafangyi query overworld
/plre bafangyi query overworld village
```

## 传送规则

| 条件 | 说明 |
|------|------|
| 大项解锁 | 大项必须已解锁 |
| 子项解锁 | 子项必须已解锁 |
| 经验值 | 消耗 10 点经验值，不足时无法传送 |
| 物品冷却 | 传送后物品进入冷却，走"冷却缩减"属性计算 |
| 持久冷却 | 传送后记录持久冷却时间，退出重进不会重置 |

### 冷却计算

物品冷却 = `600 × (2 - 冷却缩减属性值)` ticks

- 冷却缩减 = 1.0 时，冷却为 600 ticks（30 秒）
- 冷却缩减 > 1.0 时，冷却缩短
- 八方归位仪手持时自带 +1.0 冷却缩减
- 持久冷却采用相同公式，存储在玩家数据中

---

## 数据存储

玩家解锁进度和传送冷却存储在 `BaFangYiData` attachment 中，格式如下：

- `unlocked`: `Map<String, Set<String>>` — 大项 id → 已解锁子项 id 集合
- `teleportCooldownEnd`: `long` — 传送冷却结束的世界时间

Attachment 随玩家数据自动持久化（`copyOnDeath`），玩家死亡或退出重进均保留。

---

## 注意事项

1. JSON 配置文件必须使用 UTF-8 编码
2. 配置文件变更后需重载资源包或重启服务端
3. 传送点坐标使用世界坐标，建议先在目标位置记录
4. 传送前会自动让玩家下马/下车（`unRide`）
5. 传送保留玩家的视角方向（YRot / XRot）
6. 冷却缩减属性可叠加（手持八方归位仪 + 其他装备/饰品）
7. 持久冷却和物品冷却独立计算，两者均到期后才能再次传送
